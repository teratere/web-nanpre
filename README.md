# 🔢 Webナンプレ (Number Place)

ブラウザで快適にロジックパズルを楽しめる、単一HTMLファイル完結型のナンプレ（ナンバープレイス / Number Place）Webアプリケーションです。  
伝統的な数学的パズルルール（パブリックドメイン）に完全準拠し、外部画像アセットに依存しない軽量・クリーンな設計で作られています。

---

## 🌟 主な機能 (Features)

### 1. 4段階の難易度設定
- **初級 (Easy):** ルールを覚えたての方やサクッと解きたい方向け（空白約30マス）
- **中級 (Medium):** 程よい思考とロジックを楽しめる標準難易度（空白約42マス）
- **上級 (Hard):** 複数の解法テクニックが要求される本格難易度（空白約50マス）
- **達人 (Expert):** 仮置きや高度な絞り込みが試される最高峰モード（空白約56マス）

### 2. 充実したアシスト & 操作支援
- **メモ機能 (鉛筆モード):** 候補となる数字をマスの中に小文字で複数記録可能。数字を確定入力すると、同一行・列・3×3ブロック内の該当メモが自動消去されます。
- **アンドゥ (1手戻す):** 数字の入力やメモの変更を直前の状態へスムーズに巻き戻せます。
- **ヒント機能 (3回まで):** 選択したマス（またはランダムな空マス）に正解の数字を自動配置。
- **スマートハイライト:** 選択中のマスと同じ行・列・3×3ブロック、および同一数字を瞬時に色分け表示。入力ミスがある場合は警告色で直感的に通知。
- **残り数字カウンター:** 1〜9の各数字があと何個盤面に残っているかをリアルタイム表示（すべて配置し終えると自動でチェックマークに変化）。

### 3. マルチデバイス & キーボード完全対応
- **PC操作:**
  - 矢印キー（`↑` `↓` `←` `→`）: セルの選択移動
  - `1` 〜 `9` キー: 数字の入力
  - `Backspace` / `Delete` / `0` キー: 数字・メモの消去
  - `M` キー: 通常入力とメモモードのワンタッチ切り替え
  - `Ctrl + Z`: アンドゥ
- **スマホ・タブレット操作:** 押しやすい大型オンスクリーンキーパッドで片手でも快適にプレイ可能。

### 4. タイム計測 & クリア演出
- **タイマー機能:** プレイ時間をリアルタイム計測（一時停止機能付き）。
- **ミス回数カウント:** 間違った回数を記録。
- **クリア祝賀エフェクト:** すべてのマスを正解で埋めると、紙吹雪アニメーション（Canvas Confetti）と詳細なクリア戦績ダイアログが表示されます。

## 🎮 遊び方 (How to Play)

1. **基本ルール:**
   - タテ9列、ヨコ9列、太線で囲まれた3×3のブロックそれぞれに、1から9までの数字が重複しないように配置します。
2. **操作の流れ:**
   - 盤面のマスをタップ（または矢印キーで選択）します。
   - 下部の数字ボタンまたはキーボードの `1〜9` を押して入力します。
   - 候補数字を残したいときは「メモ」ボタンをONにしてから数字を押します。
